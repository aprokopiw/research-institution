## How the dispatcher reads this file

The dispatcher does **not** parse this file. It just shells out to
`pi-monitor watch --config <this-path>`. The path comes from
`MATHLINT_PI_MONITOR_CONFIG` if set, else `~/.config/mathlint/local-pi-monitor.toml`.

## Editing this file

1. Stop the supervisor: there is no `pi-monitor stop` verb; the supervisor
   is meant to be long-running. To reload config, kill the supervisor
   process and let the dispatcher restart it.
2. Edit `~/.config/mathlint/local-pi-monitor.toml`.
3. Run `python -m research_institution doctor` to confirm the new config
   loads cleanly.
4. Run `python -m research_institution start <program>` to restart the
   supervisor with the new config.
