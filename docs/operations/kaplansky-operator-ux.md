# Kaplansky Operator UX

The kaplansky operator surface is the **dispatcher CLI** + **per-program
pi skill**. The dispatcher is the only application code in this repo
(see `@ADR-0006`); the pi skill is a thin wrapper over the dispatcher.

## Install (once per fresh checkout)

```sh
python -m research_institution install-skills
```

This generates one skill markdown per catalog entry, symlinked into
`$PI_AGENT_SKILLS_DIR` (default `~/.pi/agent/skills/`). Idempotent.

## Commands

| Verb | Command | Backed by |
|---|---|---|
| Start | `python -m research_institution start kaplansky [--dry-run]` | mathlint live-run |
| Stop | `python -m research_institution stop kaplansky` | mathlint research-stop |
| Status | `python -m research_institution status kaplansky` | mathlint research-status |
| Watch (TUI) | `python -m research_institution watch kaplansky` | pi-monitor watch |

All commands honor `MATHLINT_INSTITUTION_DIR` (defaults to
`~/Documents/andrei/research-institution`).

## Pi skill

The `/skill:kaplansky` skill is generated by `research install-skills`.
From any pi session:

```text
/kaplansky start
/kaplansky stop
/kaplansky status
/kaplansky watch
```

The skill is a thin pointer to the dispatcher CLI; no logic in the skill
itself.

## Live monitoring (TUI)

For a live view of the running supervisor:

```sh
python -m research_institution watch kaplansky              # 2s refresh (default)
python -m research_institution watch kaplansky --interval 1 # faster refresh
```

The TUI is owned by `pi-monitor` (`pi-monitor watch`). See
`docs/operations/dispatcher-cli-reference.md#watch` for keybindings +
panel layout.

## Architecture-review gate

`research start kaplansky` (non-`--dry-run`) refuses to launch while
the architecture-review gate is closed. The gate verdict is delegated
to `mathlint architect-review` once `@ADR-0007` (cross-repo) ships.

Today, when the gate is closed, the dispatcher surfaces a clear
`GATE NOT OPEN` line and exits 1. Use `--dry-run` to see what would
launch without making the check. See
`docs/operations/architecture-review-gate.md`.
